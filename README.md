# Python-Obchodnik
Učím se v pythonu chvilku a protože se chci učit na konkrétním projektu a nikdy se mi neslo učit učebnicově "jen tak", tak jsem si zvolil to, co je mi nejbližší = videohry

Jednoduchá textová RPG s nádechem kyberpunku. Zkouším si herní mechaniky jako:
- dialogy
- systém inventáře
- systém obchodování
- reputace

Hra se ovládá klasickými input příkazy (1,2,3 NEBO konkrétními přesnými příkazy z nabídky).

Hra není dlouhá, obsahuje jen tři lokace, ale nechci si toho na sebe zatím nakládat tolik.
Uvidíme co z toho ve finále vznikne :-)
